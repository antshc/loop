# Orb Overview

Orb is the CLI and top-level product. Ralph, the orchestrator, is delivered as a Copilot plugin (`ralph`) of skills for an autonomous development loop and PR review handling, backed by a Python tooling package (`brain-tools`) that exposes the `afk_dev`, `afk_fix_prs`, and `afk_address_prs` CLIs; Crew agents (Codey, Chorey, Testy) do the work inside Capsules from Tickets.

## Goal

Build a headless AI development environment that orchestrates coding agents across Git repositories, manages isolated single-repository and multi-repository harnesses, and supports iterative autonomous development workflows with minimal human intervention.
