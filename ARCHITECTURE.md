# Loop Overview

Loop is a TypeScript library run by Bun, installed as a Bun package from this repository, for composing autonomous agent Workflows on Git worktrees. It ships no command and no built-in Workflows: the user writes each Workflow as a plain script on the public `loop` API and runs it through their own shell alias. Ralph, the orchestrator, drives the autonomous development loop; Crew agents (Codey, Chorey, Testy) do the work on worktrees from Tickets.

## Goal

Build a headless AI development environment that orchestrates coding agents across Git repositories, manages isolated single-repository and multi-repository harnesses, and supports iterative autonomous development workflows with minimal human intervention.
